Privacy Policy

Quiet Conservatory Streamer is a personal tool used only by the owner of one YouTube channel.

Data accessed: with the owner's permission, the tool accesses that channel's live broadcast and video settings through the YouTube Data API, only to manage the channel's own live streams.

Storage: the sign-in token is stored only on the owner's private server and is never shared or sold. No data from other users is collected.

Revoking access: access can be removed at any time at myaccount.google.com/permissions.
